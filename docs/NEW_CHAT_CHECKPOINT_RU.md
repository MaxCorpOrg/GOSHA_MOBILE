  - `feature/mobile-hotspot-portal`
- В этой ветке уже сделана рабочая правка пользовательского пути локального портала:
  - `MainActivity.startRobotWifiPortal()` открывает `http://192.168.4.1` через системный браузер;
  - если браузер открыть не получится, остаётся запасной встроенный экран `HotspotPortalActivity`;
  - в запасном экране оставлены дополнительные диагностические сообщения `HotspotPortal`.
- `2026-05-27` подтверждено на живом телефоне:
  - лишние старые пакеты удалены;
  - на устройстве оставлен только `com.maxcorp.gosha.mobile`;
  - после нажатия `Подключить робота` приложение действительно открывает `Chrome`;
