# AGENTS.md

`docs/` — это контрольные точки и рабочая документация проекта `GOSHA_MOBILE`.

## Правила

- Документы должны описывать именно новый клиент `Гоша`, а не старый опубликованный контур.
- Пиши новые записи русским техническим языком.
- Не используй русско-английский суржик в обычном тексте.
- Если термин нужен, сразу дай русское значение.
- Для типовых слов используй такие формы:
  - `verified online` — подтверждённо в сети
  - `detect` — обнаружение
  - `handshake` — проверочный обмен запрос-ответ
  - `scope` — область изменений
  - `branch` — ветка
  - `commit` — коммит
  - `push` — отправка изменений
  - `pull` — получение изменений
- После значимой задачи синхронизируй:
  - `PROJECT_STATUS_RU.md`
  - `AGENT_CHECKPOINT_RU.md`
  - `NEW_CHAT_CHECKPOINT_RU.md`

## Что обязательно фиксировать

- что уже сделано;
- на чём остановились;
- какие есть риски;
- что делать следующим шагом;
- если менялся серверный пакет подключения, где именно это отражено в `GOSHA_PLATFORM`.
