# Живая проверка приложения с роботом

Дата решения владельца: `2026-09-03`.

Неисправная левая серва робота физически отключена от платы. Прежний общий
запрет снят. Для разработки Android-приложения разрешено подключать робота,
устанавливать проверяемую прошивку, перезагружать устройство и отправлять
команды движения исправным приводам.

Перед тестом робот ставится устойчиво, зона движения освобождается, а питание
остаётся доступным для немедленного отключения. Первые команды выполняются
коротко, с малой скоростью и амплитудой. Тест прекращается при неожиданном
движении, перегреве, постороннем звуке, повторном reset, brownout или потере
управления. Левую серву нельзя подключать обратно или подталкивать под
питанием.

В Draft Pull Request нужно указать commits приложения и прошивки, сценарий и
фактический результат. Не публиковать реальные endpoints, Wi-Fi-пароли,
device keys, токены или приватные логи. Production deployment и merge
согласуются отдельно.

Этот документ отменяет прежние текущие инструкции `no flash`, `no motion` и
ожидание замены левой сервы. Исторические checkpoint-факты остаются историей.
