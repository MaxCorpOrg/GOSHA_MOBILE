# GOSHA_MOBILE

Основная документация проекта находится в [README_RU.md](README_RU.md).

Коротко:

- `GOSHA_MOBILE` — отдельный Android-клиент платформы `Гоша`;
- проект создан одноразовым копированием старого клиента и дальше развивается независимо;
- рабочий серверный контур приходит из runtime-конфигурации:
  - панель задаётся через `GOSHA_PANEL_BASE_URL` или пакет подключения
  - серверный `WebSocket` и `MCP`-контур задаются через поля пакета подключения
  - временный live relay обозначается только как `TEMP_NL_RELAY` до переезда на `FUTURE_PRODUCTION_SERVER`
- пользовательский префикс сети робота:
  - `GOSHA-`
- переходная техническая совместимость со старым префиксом:
  - `Xiaozhi-`
