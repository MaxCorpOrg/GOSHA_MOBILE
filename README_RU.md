# GOSHA_MOBILE

`GOSHA_MOBILE` — отдельный Android-клиент платформы `Гоша`.

## Что это за проект

- Это самостоятельный Android-проект.
- Он был создан одноразовым копированием исходников из старого клиента `AI_ROBOT`, но дальше развивается отдельно.
- Старое опубликованное приложение не является главным объектом этой папки.
- Новый канонический пакет приложения:
  - `com.maxcorp.gosha.mobile`

## Общая карта проекта

Если нужно быстро понять, где сервер, голоса, прошивка и мобильный контракт, сначала открой:

- `/home/max/GOSHA_PLATFORM/docs/GOSHA_PROJECT_MAP_RU.md`

## Основная задача

Клиент должен:

- принимать код подключения;
- работать с `GOSHA_PLATFORM`;
- находить робота в домашней сети через локальный `WebSocket` `ws://<ip>:8080/ws`;
- при необходимости переводить пользователя в портал настройки робота `http://192.168.4.1`;
- использовать новый серверный контур `Гоша`, не завязываясь на старый серверный контур.

## Runtime-адреса

- панель:
  - задаётся через `GOSHA_PANEL_BASE_URL` или пакет подключения
- совместимый серверный контур:
  - задаётся через поля `cloud_endpoint`, `edge_hub_url` и связанные runtime-значения
- временный live relay:
  - обозначается только как `TEMP_NL_RELAY` до переезда на `FUTURE_PRODUCTION_SERVER`
- локальный портал робота:
  - `http://192.168.4.1`

## Wi‑Fi и бренд

- Пользовательский префикс сети робота:
  - `GOSHA-`
- В переходный период приложение технически принимает и старый префикс:
  - `Xiaozhi-`
- В пользовательских текстах нужно показывать только `GOSHA-`.
- В дереве исходников Android-код пока ещё лежит в старом пути:
  - `app/src/main/java/com/maxcorp/edgeconnector`
  Это исторический след одноразового копирования, а не продуктовый бренд.

## Сборка

Локальная проверка:

```bash
cd /home/max/GOSHA_MOBILE
./gradlew --no-daemon clean assembleClientDebug testClientDebugUnitTest lintClientDebug
```

Важно:
- после правок в flow подключения безопаснее запускать эту проверку одним последовательным вызовом, а не несколькими параллельными командами `gradlew`, чтобы не получить ложные ошибки в общем каталоге `build/`.

Сборка клиентского релиза:

```bash
cd /home/max/GOSHA_MOBILE
./gradlew --no-daemon assembleClientRelease
```
