## Главные правила

- В пользовательском тексте показывать бренд `Гоша`.
- В логике сети робота принимать оба префикса:
  - `GOSHA-`
  - `Xiaozhi-`
- Не возвращать клиент на старые адреса `8876/8890`.
- После Android-правок обязательно проверять:
  - `./gradlew --no-daemon assembleClientDebug`
  - `./gradlew --no-daemon testClientDebugUnitTest`

## Язык и формат

- Пояснения по пользовательскому интерфейсу, подключению к роботу и локальному порталу пиши нормальным русским техническим языком.
- Не используй русско-английский суржик в обычном тексте.
- Если термин технический важен, сразу поясняй его смысл по-русски.
- Для типовых слов используй такие формы:
  - `verified online` — подтверждённо в сети
  - `detect` — обнаружение
  - `handshake` — проверочный обмен запрос-ответ
  - `scope` — область изменений
  - `branch` — ветка
  - `commit` — коммит
  - `push` — отправка изменений
  - `pull` — получение изменений
- Английский оставляй только для команд, путей, имён файлов, функций, переменных, веток, коммитов и кода.
