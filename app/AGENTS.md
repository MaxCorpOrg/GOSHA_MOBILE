# AGENTS.md

`app/` — это Android-код клиента `Гоша`.

## Перед правками

1. Прочитай:
   - `../AGENTS.md`
   - `../docs/AGENT_CHECKPOINT_RU.md`
   - `../docs/PROJECT_STATUS_RU.md`
2. Проверь, не ломает ли изменение:
   - ввод кода подключения
   - локальный поиск `ws://<ip>:8080/ws`
   - переход в `http://192.168.4.1`
   - чтение `bundle.panel_url`
   - чтение `bundle.mobile_profile`

## Правила

- Пользовательский слой приложения должен говорить только про `Гоша`.
- Техническая совместимость с `Xiaozhi-` допустима только как переходный механизм.
- Новый клиент должен принимать серверные дополнительные поля, не требуя удаления старых.
- Не добавляй жёсткие зависимости на старые адреса `8876/8890`.
- Все внешние адреса по умолчанию должны соответствовать `GOSHA_PLATFORM`:
  - панель `18876`
  - серверный контур `18080`

## Язык и формат

- Пиши пояснения по Android-потоку, сети и диагностике русским техническим языком.
- Если термин нельзя убрать, сразу поясняй его смысл по-русски.
- Не используй русско-английский суржик в обычном тексте.
- Для типовых слов используй такие формы:
  - `verified online` — подтверждённо в сети
  - `detect` — обнаружение
  - `handshake` — проверочный обмен запрос-ответ
  - `scope` — область изменений
  - `branch` — ветка
  - `commit` — коммит
  - `push` — отправка изменений
  - `pull` — получение изменений
- Английский оставляй только для команд, путей, имён файлов, функций, переменных, веток, коммитов и кода.
